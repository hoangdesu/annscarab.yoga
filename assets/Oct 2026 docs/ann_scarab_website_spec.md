# Ann Scarab Yoga Website — Implementation Specification

## 1. Project Overview

**Brand:** Yoga with Ann Scarab  
**Primary domain referenced:** `annscarab.com`  
**Alternate domain mentioned in the conversation:** `annscarab.yoga`

Build a calm, refined, nature-inspired yoga website that extends the existing **Ann Scarab A5 brochure** into a cohesive digital experience.

The website should feel like entering a peaceful natural space rather than a conventional commercial yoga site.

### Core themes

- Breath
- Movement
- Balance
- Well-being
- Nature

### Primary visual principle

The brochure is the source of truth for the brand identity. The website must feel like the **same brand as the brochure**, not a separate or generic yoga template.

---

## 2. Brand Identity

### Logo and brand name

Use the existing brochure logo and brand treatment.

Display:

**Yoga with Ann Scarab**

Requirements:

- Match the brochure's typography/font character as closely as technically possible.
- Preserve the brochure's proportions, spacing, and visual feel.
- Do not replace the brand treatment with a generic yoga font.
- Do not redesign the logo unless explicitly requested later.

### Brand consistency

Carry the brochure's visual language into:

- Headings
- Navigation
- Buttons
- Section dividers
- Footer
- Spacing
- Color palette
- Photography treatment

---

## 3. Visual Direction

### Overall aesthetic

- Calm
- Natural
- Elegant
- Warm
- Minimal
- Restorative
- Contemporary but timeless

### Color direction

Derive the final palette from the brochure and supplied nature photography.

Primary direction:

- Soft greens
- Warm beige / cream
- White
- Earthy brown / wood tones
- Very subtle warm sunlight tones

Do not introduce loud or unrelated colors.

### Layout

- Generous whitespace
- Large photographic areas
- Short, readable text blocks
- Clean alignment
- Soft section transitions
- Strong mobile responsiveness
- Avoid visual clutter

### Avoid

- Loud colors
- Heavy gradients
- Busy animations
- Generic stock-yoga aesthetics
- Overly spiritual/religious presentation
- Excessive text
- Aggressive promotional design

---

## 4. Photography

Use the user's supplied nature photographs as a major part of the site.

Photography themes include:

- Forests
- Sunlight through trees
- Flowers
- Gardens
- Seasonal nature
- Winter / quiet landscapes
- Natural light

### Recurring visual motif

**Sunlight passing through trees** should be a recurring visual element.

### Suggested image usage

- **Hero:** forest + sunlight
- **Breath section:** sunlight / trees
- **Therapeutic section:** flowers / natural landscape
- **Gallery:** forest, flowers, light, seasons
- **Contact/Footer:** peaceful landscape

Prefer authentic user-provided photography over stock imagery.

## 6. Hero Section

### Purpose

Create an immediate emotional impression of calm, nature, and mindful movement.

### Visual

Use a full-width nature image, ideally a forest scene with sunlight passing through trees.

### Content

**Yoga with Ann Scarab**

## Breathe • Move • Heal

Supporting text:

> Discover the power of mindful breathing, gentle movement, and therapeutic yoga to restore balance, reduce stress, and support your well-being.

### CTAs

Primary:

**Book a Class**

Secondary:

**Learn More**

### Motion

Use only very subtle effects:

- Slow image movement if desired

---

## 7. Breath Section

This is one of the most important sections of the website.

# Breath is the First Medicine

Use a calm nature / sunlight image.

### Core copy

> Every breath influences both body and mind.
>
> Gentle, mindful breathing helps reduce stress, calm the nervous system, improve circulation, and support the body's natural ability to restore balance.
>
> Through breath, movement, and awareness, yoga becomes a pathway to greater ease, strength, and well-being.

### Content intent

Communicate that breathing is central to everyday well-being, not merely an accessory to yoga.

### Medical-content principle

Use careful, support-oriented language. Avoid promising to diagnose, cure, or treat diseases. Avoid exaggerated medical claims.

---

## 8. No Philosophy-Quote Section

The client explicitly decided **not to use philosophical quotes or decorative brand-philosophy statements** as a major element of the site.

Do not build the website around quotations such as:

- “The mind guides the breath…”
- Other invented or unattributed philosophical sayings

The feeling should come primarily from:

**Photography + simple language + whitespace + calm interaction design**

## 16. UX and Motion

The website should feel **slow, gentle, and breathable**.

### Recommended effects

- Fade-in on scroll
- Very subtle image movement
- Smooth section transitions
- Gentle hover states
- Smooth scrolling
- Responsive mobile behavior

### Avoid

- Aggressive parallax
- Excessive animation
- Loud motion
- Auto-opening popups
- Overuse of interactive effects

A user should feel calmer, not overwhelmed, while scrolling.

---

## 17. Responsive Requirements

The site must be fully responsive.

### Desktop

- Spacious layout
- Large photography
- Two-column content where appropriate
- Comfortable navigation spacing

### Tablet

- Preserve generous whitespace
- Collapse multi-column sections where needed

### Mobile

- Stacked sections
- Large readable text
- Touch-friendly buttons
- No horizontal overflow
- Images cropped carefully so key subjects remain visible
- Navigation converted to an accessible mobile menu

---

## 18. Accessibility

Implement standard accessible web practices:

- Semantic HTML
- Correct heading hierarchy
- Keyboard-accessible navigation and buttons
- Visible focus states
- Sufficient text/background contrast
- Descriptive alt text for meaningful images
- Decorative images marked appropriately
- Respect `prefers-reduced-motion`

Avoid using animation as the only way to communicate information.

## 22. Design System Guidance

Create reusable components for:

- Header / navigation
- Logo lockup
- Hero
- Section heading
- Text + image section
- Service card
- Class card
- Gallery tile
- CTA button
- Contact block

Use a consistent spacing scale, border radius, typography scale, and button treatment throughout.

## 23. Source of Truth

When a conflict occurs, use this priority order:

1. **Existing brochure branding**
2. **User-provided photography**
3. **This specification**
4. Generic framework/theme defaults

Do not let a website template override the brochure's visual identity.

## 24. Final Experience Goal

The finished website should communicate:

- Calm
- Trust
- Nature
- Breath
- Gentle movement
- Therapeutic care
- Personal connection

It should feel less like an online advertisement and more like a **quiet, welcoming space**.

The ideal visitor journey is:

**See the light → slow down → read about breath → meet Ann → discover therapeutic yoga → explore classes → feel comfortable booking a class.**
